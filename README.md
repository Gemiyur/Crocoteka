# Крокотека
Библиотека электронных книг на локальном компьютере.

В библиотеку могут быть добавлены:
- Аудио книги: M4B, MP3
- Текстовые книги: EPUB, FB2, FB3, PDF, RTF, TXT, DOCX, ODT

Библиотека поддерживает серии и жанры (теги) книг, сведения об авторах, сериях и файлах книг.

Запущен может быть только один экземпляра приложения.  
В случае попытки запуска, при запущенном приложении, активируется уже работающий экземпляр.
